About
0G is the blockchain for AI agents. Verifiable compute, sealed inference, and decentralized storage in one modular stack - so developers can build autonomous AI agents whose every action (inference, memory, execution) is cryptographically verified and settled onchain instead of blindly trusted.

The product layer. Build the best end-user applications and agents on 0G: things people, or other agents, actually use. Because you build on 0G Compute / Private Computer, your inference is private and verifiable by default (TEE-sealed), so you can focus on shipping a real product. Combine with 0G Storage for persistent encrypted memory, Agentic IDs for ownership and composability, and 0G Chain for on-chain actions and micropayments.

This track is for what you ship, not what others build on. If you are building a framework, SDK, or developer tooling, submit to the Infrastructure track instead.

Ideas to get you started: 🔹 Private personal "Digital Twin" or coding agent on 0G Compute with evolving encrypted memory on 0G Storage 🔹 Verifiable research or analysis agent that self-fact-checks, with TEE-attested proof of every result, and optional on-chain provenance 🔹 Agentic browser companion or extension with tradeable memory via Agentic ID 🔹 Consumer on-chain AI app, DeFi experience, RWA tool, or AI x gaming dApp with persistent-memory agents and automatic royalty splits 🔹 Agent minted as an Agentic ID with embedded intelligence (encrypted on 0G Storage), persistent memory, and dynamic upgrades
